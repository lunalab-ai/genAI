# 과제 1 · 캠퍼스 팝업 스튜디오 기본값 결정

수업에서 만든 내 Colab 사본을 여세요.

개인 과제입니다. 마감은 2026년 12월 3일(목) 23:59 KST입니다. 무료 CPU 환경에서 진행하며 코딩 에이전트 없이 작성합니다.

## 1. 수업 실습을 이어서 제출하기

| 순서 | Colab과 화면 | 학생이 할 일 |
|---|---|---|
| 1 | 01 마스크 · 02 문서 선택 | 사진 워크숍 라벨을 완성해 '마스크 확인 완료'를 봅니다. 북토크의 k=2 문서 ID와 본문이 반환되는지 확인합니다. |
| 2 | 03–04 모델과 공통 실험 | 수업 학습 4회와 과제 24회의 차이를 확인합니다. 05를 실행하면 독립영화와 빈티지 마켓에서 A 기본·B 검색·C 검색+LoRA를 실행합니다. 영화는 신청이 미정이고 마켓의 다섯 항목은 확정입니다. |
| 3 | 05 설계와 검증표 | D 변수 하나와 가설을 기록합니다. 문서 2→1 또는 rank 4→2 중 하나입니다. B/C/D 검증 6건씩을 비교하고 표의 규칙으로 기본값을 선택합니다. |
| 4 | 06 운영 화면 | **앱 기본값 적용 → 참가비 2,000원 공지 반영**을 누릅니다. 운영값, 같은 설정 ID, 다른 문서 버전과 프롬프트 변경 여부를 확인합니다. |
| 5 | 07 오류와 제출 | 서로 다른 두 실행에서 오류를 하나씩 적어 자기검사를 통과하세요. **과제 ZIP 다운로드**의 w13a-design-submission.zip 한 개를 SmartClass → 생성형 인공지능 01 → 과제 1에 첨부합니다. |

A→B는 생성기의 다른 설정을 유지하고 근거만 추가합니다. B→C는 같은 근거를 유지하고 어댑터만 추가합니다. D는 C에서 k 또는 rank 중 하나를 바꿉니다. rank 경로의 배율 α/r은 2를 유지합니다. 두 공식 사례와 검증 사례를 어댑터 학습에 넣으면 안 됩니다.

일시·장소·참가비 중 두 값이 맞으면 핵심 사실은 **2/3**입니다. 날짜를 맞혀도 잘못된 문서 ID를 붙이면 출처 검사는 실패합니다. FAQ에 신청 정보가 없을 때 '확인 필요'는 미정 처리입니다. 신청 방법을 지어 쓰면 자료 밖 값, 줄 자체가 없으면 출력 누락입니다. 모델 에러를 원문에서 정확히 찾으면 평가받을 수 있습니다.

**기본값 규칙** · B/C/D에서 자료 밖 값 수가 가장 작은 설정을 먼저 고릅니다. 같으면 핵심 사실 일치, 유효 출처가 많은 쪽을 차례로 고릅니다. 계속 같으면 입력 토큰 합, 학습 가능 스칼라가 적은 쪽을 고릅니다. 모두 같으면 B, C, D 문자 순서입니다.

실제 24회 학습·생성은 05의 HOMEWORK_LIVE를 True로 실행합니다. 다운로드나 런타임이 어려우면 False로 설정해 동일 조건에서 사전 측정한 기록으로 진행합니다. 제출에는 실행 경로가 표시됩니다. 두 경로는 같은 10점 기준을 적용합니다. 자유 문장과 화면 디자인에는 배점이 없습니다.

자기검사 메시지는 **생성 26건 · 검증 130행 · 요약 6행**입니다. 수치·원문·해시는 앱에서 내보낸 대로 제출하세요. 바뀐 참가비가 화면에서 보이면서 프롬프트에는 없을 수 있습니다. 사용 문서 ID에 갱신한 운영 메모가 포함됐는지 확인하세요.
