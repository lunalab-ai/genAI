## 1. 분산과 표준편차를 구별하는 작은 계산

평균0, 분산1인 독립 변수 $z_1,z_2$를 생각하자. $0.8z_1+0.6z_2$의 분산은 $0.8^2+0.6^2=1$이다. 0.8과0.6을 더한 값1.4가 아니다. 독립성 때문에 공분산 항이0이 되는 것이 핵심이다.

**계산 W1.** 원본을 상수0.5로 두고 잡음의 표준편차를0.6으로 만들려 한다. 표준정규 잡음에 무엇을 곱해야 하는가? `0.36*noise`를 쓰면 잡음 분산은 어떻게 달라지는가?

| 원하는 잡음 표준편차 |  |  | 픽셀 값의 흔들림 |
| 잘못된 계수를 사용한 분산 |  |  | 제곱 단위 |

## 2. 두 단계 전방 과정을 직접 펼치기

$$x_1=\sqrt{0.9}\,x_0+\sqrt{0.1}\,z_1,\qquad x_2=\sqrt{0.8}\,x_1+\sqrt{0.2}\,z_2.$$

**계산 W2.** 첫 식을 두 번째 식에 넣어 원본의 계수를 구하고, 독립 잡음 두 항의 분산을 합하자. 누적 alpha가0.72임을 사용해 직접식과 대조한다. 계수 합과 분산 합을 구별한다.

## 3. 동일 픽셀을 세 목표로 표현하기

$x_0=0.5$, $\epsilon=-1$, $a=0.8$, $b=0.6$을 사용한다.

| 값 | 자신의 계산 | 설명 |
|---|---|---|
| noisy 픽셀 $x_t$ |  | 원본과 잡음을 섞은 값 |
| epsilon target |  | 직접 뽑은 정답 잡음 |
| sample target |  | 원본 픽셀 |
| v target |  | 표준 정의의 빼기 부호 확인 |
| epsilon에서 복원한 원본 |  | noisy 입력과 예측의 역할 |
| v에서 복원한 원본 |  | 역변환으로 부호 검산 |

**계산 W3.** $a$가 작을 때 epsilon 예측 오차가 원본 추정 오차로 얼마나 확대되는지 설명하자. 정답 target으로 복원한 결과와 학습된 예측으로 복원한 결과를 비교한다고 할 때, 각각 무엇을 검증하는지도 적는다.

## 5. 실행이 막힐 때

| 증상 | 확인할 것 | 다시 시작할 위치 |
|---|---|---|
| 패키지·함수 이름을 찾을 수 없음 | 첫 설치 셀의 성공, 고정 버전0.1.9 | 새 런타임의 첫 셀 |
| 설치 후에도 이전 코드가 실행됨 | 이미 import한 모듈이 메모리에 남았는지 | 런타임 재시작 후 첫 셀 |
| MNIST 다운로드 오류 | 인터넷 연결과 캐시 검사 메시지 | 데이터 준비 셀 |
| shape 또는 시점 오류 | `(B,1,28,28)`, int64 `(B,)`, 코드0..99 | 해당 입력을 만드는 셀 |
| 앱 링크가 열리지 않음 | 마지막 서버 셀·런타임의 실행 상태 | 마지막 launch 셀과 새 링크 |
| 생성 그림이 좋지 않음 | initial/짧은 학습/trained의 구별 | 학습 기록·평가·전체 격자 확인 |

오류를 가짜 출력으로 바꾸지 않는다. 빈칸 연습용 변수와 기본 실험 변수를 구별하고, 파일 저장과 런타임의 메모리 상태도 구별한다. Colab 공유 앱은 새 탭에서 직접 버튼을 눌러 확인한다.
