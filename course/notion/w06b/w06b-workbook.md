## 3. 데이터와 실행 경로

Fashion-MNIST는 처음 약 30 MB를 받고 체크섬을 검사합니다. 저장된 이미지·체크포인트는 패키지에 포함됩니다. SD 직접 생성은 모델 가중치를 처음 약 2.6 GB 내려받습니다. API 키·개인 사진 업로드는 필요 없습니다.

| 경로 | 실제로 하는 일 | 했다고 말할 수 없는 일 |
| --- | --- | --- |
| A CPU | 작은 조건부 모델 학습·생성 | SD 모델 학습 |
| B 기록 모드 | 검증된 실제 생성 이미지와 중간 텐서 읽기 | 지금 SD 생성 실행 |
| B GPU 모드 | 고정 SD 1.5로 새 이미지 생성 | 새 프롬프트에 맞춘 가중치 학습 |

기록 모드는 실패를 감추는 대체 출력이 아닙니다. 처음부터 선택하는 분석 경로이며 화면에 재생이라고 표시합니다. 직접 생성이 실패하면 오류를 확인하고, 모드를 바꿨다는 사실을 기록하세요. CPU에서 SD 전체 모델을 직접 실행할 수는 있지만 수업 기본 경로로 권하지 않습니다.
