| 질의 | 관련 ID 집합 | top3 ID·점수 | P@3 | 이 모음의 가능한 P@3 상한 | 해석 |
|---|---|---|---|---|---|
| a cat in the snow | | | | | |
| a cat and a lizard | | | | | |
| a horse on a beach | | | | | |

이어서 같은 k=3에서 “a cat indoors”와 “a cat in the snow”를 비교한다. 겹치는 사진 하나를 골라 **대상은 맞는지, 속성은 맞는지** 따로 적는다. 같은 의미의 한국어 질의는 선택 탐색이며, 한 결과로 전체 언어 성능을 일반화하지 않는다.
