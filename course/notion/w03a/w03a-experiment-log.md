## 수치 확인

어텐션 행합, 미래 위치의 가중치, 출력 모양을 기록한다. 강의의 3토큰 수치는 가상 예이며 실제 Qwen 관측값과 구분한다.

| 관측 대상 | 실제 값 | 예상과 차이가 있으면 확인할 항목 |
|---|---|---|
| 행합 | | softmax 축 |
| 미래 위치 | | 마스크 적용 시점 |
| 출력 모양 | | 위치 축과 Value 특징 축 |

## 생성 비교

| 실험 | 프롬프트 | 규칙 | 온도 | top-k | seed | 길이 한도 | 실제 출력과 종료 이유 |
|---|---|---|---|---|---|---|---|
| 기준 | | greedy | 적용 안 됨 | 적용 안 됨 | | | |
| 비교 1 | 동일 | sample | 0.4 | 10 | 7 | 동일 | |
| 비교 2 | 동일 | sample | 1.2 | 10 | 7 | 동일 | |

바꾼 조건과 고정한 조건을 명시한다. 출력이 같을 수도 있으며, 한 번의 출력으로 품질 우열을 확정하지 않는다. 개별 토큰 확률을 사실성 확신도로 해석하지 않는다.

## 앱 연결 점검

직접 함수 호출과 버튼 callback에 같은 입력을 넣고 문장·표 행 수·종료 이유를 비교한다. 모델을 요청마다 다시 만들지 않았는지 확인한다. 기본 한 단계 모드에서 자동 반복을 구현하지 않았다면 그 상태를 명시한다.

실제로 구현한 기능, 관측한 차이, 아직 검증하지 못한 환경이나 입력, 다음에 바꿀 조건을 각각 한 문장으로 기록한다. [강의노트](w03a-transformers.md)의 점검 퀴즈와 연결하여 복습한다.
