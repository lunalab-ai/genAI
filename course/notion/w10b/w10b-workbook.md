## 블라인드 전후 평가

쌍의 순서를 가리고 독립적으로 먼저 평가한 뒤 전후 라벨을 공개합니다. 같은 seed라도 환경이 다르면 pixel 동일을 보장하지 않습니다. 안전 필터가 차단한 항목은 이미지 없음/평가 제외로 적고 성공 사례로 바꾸지 않습니다.

| 실제 조합ID / 실행 모드 | 대상 속성(몸체·패치·손잡이) | 배경/지시 이행 | 미사용 맥락 | 기존 클래스 다양성 | 근거·한계 |
|---|---|---|---|---|---|
| familiar / seed42 | | | | | |
| new_scene / seed42 | | | | | |
| class / seed42 | | | | | |
| unrelated / seed42 | | | | | |
| 다른 seed 또는 차단 상태 | | | | | |

지표를 억지로 합산하지 않습니다. MSE와 사람이 읽은 대상 보존은 다른 증거입니다. 한 seed의 좋은 그림만 골라 일반화하지 않습니다.
