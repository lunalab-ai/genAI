# 소리를 생성해 듣고, 생성형 AI의 발전과 최신 동향 읽기 · 퀴즈 해설

학생용 개념 자기 점검의 짧은 설명

## 1. STFT 분석 창을 바꿔도 WAV가 그대로라는 사실을 어떻게 보여 줄 수 있나요?

같은 WAV를 두 함수 호출에 입력하고 출력 그림만 비교합니다. WAV의 바이트 또는 읽어 온 PCM 샘플 배열이 같은지 검사합니다.

## 2. SpeechT5에서 멜 프레임과 WAV를 만드는 부분은 각각 무엇인가요?

SpeechT5 생성 디코더는 멜 프레임을 예측하고 HiFiGAN vocoder는 그 프레임에서 파형을 생성합니다.

## 3. 긴 입력을 받는 능력과 긴 문서에서 근거를 찾는 능력을 어떻게 따로 확인하나요?

허용되는 입력 길이를 확인한 뒤, 같은 근거를 앞·가운데·끝으로 옮긴 문서에 같은 질문을 해 정답률과 인용을 비교합니다.

## 4. MoE의 전체 파라미터와 토큰당 활성 파라미터는 어떤 기준으로 셉니까?

전체는 저장된 모든 파라미터이고, 토큰당 활성은 그 토큰의 처리에 실제 쓰이는 공통 부분과 선택된 전문가의 파라미터입니다.

## 5. 상대 깊이 지도, 탐지 상자, 캡션은 각각 어떤 질문에 답하는 출력인가요?

지도는 무엇이 상대적으로 가까워 보이는지, 상자는 무엇이 어디 있는지, 캡션은 무엇이 보이는지를 문장으로 설명합니다. 각각의 출력은 원본이나 출처와 대조합니다.
