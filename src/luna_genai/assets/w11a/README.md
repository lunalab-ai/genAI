# W11A actual execution assets

Own procedural tote-bag render, geometric reference tile and masks; no textbook scans or personal photographs. Each generated PNG was assessed by the model safety checker. These are actual SD1.5 CPU float32 execution records, mostly8steps/256px; semantic uses16steps. Not a fresh student GPU/SDXL run or a quality benchmark.

Pinned model sources and license notices:
- SD1.5: stable-diffusion-v1-5/stable-diffusion-v1-5, CreativeML OpenRAIL-M, https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5
- ControlNet Canny: lllyasviel/control_v11p_sd15_canny, OpenRAIL, https://huggingface.co/lllyasviel/control_v11p_sd15_canny
- IP-Adapter: h94/IP-Adapter, Apache2.0, https://huggingface.co/h94/IP-Adapter
- InstructPix2Pix: timbrooks/instruct-pix2pix, model-card MIT notice, https://huggingface.co/timbrooks/instruct-pix2pix

Original model use restrictions and terms continue to apply. No model weight files are bundled here. Revisions, actual settings, safety flags, timings and image SHA256 are in record-manifest.json. load_edit_records checks every recorded image before use. Source/output metadata and generator are kept for reproducibility; model outputs are not claimed as copyrighted textbook figures.
